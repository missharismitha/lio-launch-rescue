## 3. Architecture (app/)
engine.py (reconciliation: newest pack counts from launch_status.xlsx beat the plan, German number formats, estimated stock after parts used, CPO memo parsed -> Collector's-first allocation, remaining shift hours) · sync.py (portal polling) · store.py (SQLite cases/events in .local/cases.sqlite3) · investigator.py / claude_agent.py (LLM tool loop: read/search PDFs, docx, xlsx; asks for a verdict, recommended action and Plan B options as JSON) · crew.py + verify.py + actions.py (Reconciler, Investigator, Allocation Planner, Pricer, Policy Officer, Approver-Router, Drafter, Checker with a visible trace; every number in a draft is recomputed in code; escalation draft to the approver; never auto-sends) · policy.py (parses PP-07 approval policy + org charts + onboarding notes; category-specific approver; vacancies) · pricing.py (prices options from PO unit prices + assumptions in .local/assumptions.json; unknown stays null) · value.py (money at stake: EUR 80,920 cost basis = 6,800 x std cost; contract late-delivery claim) · whatif.py (copies that still ship if parts arrive at hour X) · brief.py (decision brief) · conflicts.py (places where the customer's own records disagree) · recovery.py (reply scenarios; uses policy) · mailbox.py (IMAP/EML reply ingestion, read-only, human review) · public.py + labels.py (ALLOWLIST layer: the ONLY thing that shapes API output for the browser) · access.py (optional access-code login gate, cookie, rate limit) · main.py (FastAPI, security headers, routes) · static/ (vanilla UI: index.html, app.js, styles.css, login.js).
Key rules (AGENTS.md + docs/PLAN_UI_PRIVACY.md): the browser NEVER receives documents, file names, paths, quotes or emails; /api/evidence is 404 by default; approval (named human) before any external email or spend; send disabled without a registered sender; supplier drafts contain only supplier-facing facts (tests/test_draft_privacy.py); no real email/model/network in tests; no hardcoded business numbers; changed evidence invalidates approvals.
