## D. Honest-brief rules
Feasible recovery/release (known arrival, before cutoff, gain>0): existing action text, confidence medium (high only if numbers verified, price known, ETA from a confirmed source and stock basis verified). None feasible but a release/recovery with unknown arrival: "First action: {title}. Arrival is not confirmed, so no copies are counted yet. Meanwhile allocate by the CPO priority." confidence low; if price unknown same text, verify_next leads with the freight assumption and the earliest-arrival question, risk "cost not known". Only 'late' options: "No option is confirmed in time. Allocate by the CPO priority and escalate." low, risk: earliest known arrival is after the last packing hour. Only allocation: NONE_FEASIBLE, low. A hold needs_review: verify_next adds "A person must read a scanned supplier confirmation", confidence cap low. Claim mismatch: composed text replaces model text, numbers_verified False, low. verify_next order: (1) unlock/ask-for-arrival action, (2) freight cost, (3) approver, (4) stock count.
